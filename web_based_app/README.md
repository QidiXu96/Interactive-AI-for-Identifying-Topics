### **Features**
1. **Azure API Configuration:**
   - Enter your Azure API Endpoint, API Key, Version, and Model.
   - Save configuration for easy setup.

2. **Upload an Interview File:**
   - Allows users to upload interview (.docx) files for processing.

3. **Read Dialogue:**
   - Process the uploaded file and identify topics with corresponding extracted clues and generated reasoning.<br>
   - If users are not satisfied with the current response, they can choose 'Try again" or "Provide feedback".
   - If users are satisfied with the current response, they cab choose 'I'm satisfied' to save it.

4. **Uploaded Interview Viewer:**
   - Search and view the uploaded interview file directly in the application.

This intuitive UI is designed for simplicity, allowing users to quickly configure their API settings, upload files, and analyze dialogues with ease.
